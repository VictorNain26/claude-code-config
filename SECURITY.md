# Security

Report a vulnerability privately through
[GitHub's private vulnerability reporting](https://github.com/VictorNain26/claude-code-config/security/advisories/new),
not in a public issue.

In scope: a rule in `config/settings.json` that lets Claude read or change a
secret it should not, an install, update or uninstall step that weakens a
machine's security, and an eval scaffold that runs unexpected code.

Claude Code's own behavior, such as a permission rule it doesn't enforce as
documented, goes to Anthropic under its
[responsible disclosure policy](https://www.anthropic.com/responsible-disclosure-policy).
